# OIBSIP - Python Programming Task 1: Random Password Generator

##  Task Title:
Random Password Generator

##  Objective:
To develop a Python-based application that generates strong, random passwords based on user preferences like length and character types (letters, digits, symbols).

##  Tools & Technologies:
 VS Code
 Python 
 **Libraries Used:**
  - `random`
  - `string`

##  Features:
- User-defined password length (**minimum 8 characters**)
- Option to include:
  -  Letters (A-Z, a-z)
  -  Digits (0-9)
  -  Symbols (!@#$%^&*...)
- Input validation and prompts for wrong inputs
- Strong, unpredictable password generation

##  Files Included:
- `password.py` — main Python script
- `screenshots/` — folder containing screenshots of the code
- `README.md` — project documentation

##  How It Works:
1. Run the Python script.
2. Program asks for:
   - Desired password length (must be ≥ 8)
   - Whether to include letters, digits, and/or symbols
3. Based on input, it builds a character set.
4. Randomly generates a password and displays it.
